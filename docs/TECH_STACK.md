# Tech Stack - LO&P3D Lab Manager

## Frontend

- React
- Vite
- TypeScript
- Tailwind CSS
- FullCalendar ou alternativa equivalente para visualização de agenda

## Backend

- Supabase
- PostgreSQL
- Supabase Auth
- Supabase Storage

## Deploy

- GitHub Pages para frontend
- Supabase para backend, autenticação, banco e arquivos

## Controle de versão

- GitHub

## Agente de desenvolvimento

- Codex

## Estratégia de desenvolvimento

O projeto deve ser desenvolvido em etapas pequenas, com commits separados por funcionalidade.

Ordem recomendada:

1. Estrutura inicial do projeto.
2. Autenticação.
3. Perfis de usuário.
4. Habilidades.
5. Disponibilidade dos pesquisadores.
6. Cadastro de impressoras.
7. Cadastro de materiais.
8. Agenda das impressoras.
9. Reservas manuais.
10. Validação de conflito de horário.
11. Upload de arquivos.
12. Parser de .gcode.
13. Sugestão automática de horários.
